> ⚠️ **本模块由 AI 全程编写（AI 生成代码）**：源码、构建脚本与文档均出自 AI 助手（DeepSeek Harness 中的 deepseek 系列模型），人类参与者只做真机测试与日志反馈。

## 安装

1. 下载下方 `NotificationSinking-v1.13.0.apk` 安装；
2. LSPosed 中启用模块，作用域勾选 **系统界面**（`com.android.systemui`）、**息屏**（`com.oplus.aod`，可选 `com.oplus.exsystemui`）；
3. 打开模块 App → 打开**总开关** → 按需调整下沉距离；
4. 点 App 内「**重启 SystemUI / AOD 作用域**」，无需重启手机。

> APK 为自签名。若与已装版本签名不一致，卸载重装即可（会清空配置）。

## 完整功能

| 功能 | 说明 |
|---|---|
| 通知下沉 | Hook 锁屏通知区顶部间距整体下移，**只在锁屏静止态生效**（展开通知中心不干预） |
| 音乐卡片自动让位 | 有音乐卡片时下沉自动 −150dp，保证通知堆叠不被挤出屏幕 |
| 保持大时钟 | 强制大尺寸时钟，下拉通知中心时自动让位 |
| 通知折叠 | 只显示最上面 2 条，其余收进系统「+N 条」汇总行 |
| 显示方式切换 | 系统键 `lock_screen_notification_style`：`0`＝列表/堆叠，`1`/`2`＝胶囊 |
| AOD 下沉 | 息屏通知同样下移（按固件类名候选 Hook） |

## 实测环境

OPPO Find X8（PKB110）· ColorOS 16.0.9.400 · Android 16（API 36）· LSPosed 2.1.1（KernelSU + Zygisk）

## 已知限制

- 仅在该固件验证过；类名与键名和 ColorOS 版本强相关，换机型可能需重新挖类名（模块内置诊断功能）；
- “大时钟 + 通知位置很靠上”物理上不可兼得；
- 下沉超过「屏高 − 500px」会被可见性护栏收回；
- iOS / ColorOS 17 那种精致堆叠动画属于系统层实现，本模块无法提供。
